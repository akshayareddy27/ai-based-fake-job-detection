Machine Learning Model Comparison

The system was trained on the EMSCAD dataset (17,880 postings) to compare different classifiers. The dataset exhibits a high class imbalance (~95% real vs ~5% fake). Consequently, the primary selection metric is the F1-Score for the Fraudulent class, ensuring the system minimizes false negatives while maintaining high precision.

Project Architecture & Methodology

This system leverages advanced Natural Language Processing (NLP) and supervised Machine Learning (ML) classifiers to protect job seekers from recruitment scams.

1. Raw Dataset

18-column Kaggle dataset containing 17,880 listings (866 fake, 17,014 real).

2. NLP Preprocessing

HTML stripping, lowercasing, stopword removal, and WordNet Lemmatization via NLTK.

3. Feature Extraction

TF-IDF unigram & bigram vectorizer (10,000 features) + metadata features.

4. Ensemble Classifiers

Random Forest Pipeline computes job fraud probabilities and predicts labels.

Common Scam Indicators

  • Missing Corporate Identity:

    Jobs posted without a company logo are 3.7x more likely to be fraudulent in the training dataset.

  • Lack of Screening Questions:

    Scammers rarely set up screening questions. Jobs without questions have a significantly higher risk profile.

  • Financial Buzzwords:

    Frequent usage of terms like "unlimited income", "earn money", "immediate start", "package", or "investment" are key text indicators.
